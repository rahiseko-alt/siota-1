# design/ — 意匠見本（動くコードではない）

`mock-4step.html`（2,782行）は**4ステップ・エディトリアル意匠の静的モック**です。
統合フェーズ（`docs/ops/plans/2026-08-21-integration.md` の P0〜P9）で
`src/` の DOM をこの意匠に貼り替えるための、貼り替え先の見本として置いてあります。

## ここにあるものは本体ではない

| | `src/` | `design/` |
|---|---|---|
| 位置づけ | **本番の実体**。`trimmer-system.kouheikosehira.com` で現に稼働している V1 | 意匠の見本 |
| ビルド | `npm run build` の対象 | **対象外** |
| Konva 描画エンジン | あり（`ponchi-v2.html` にインライン 966行） | **なし**（`konva` の参照 0件） |
| データ契約 | `data-field=` で保存・読み戻しに接続済み | **なし**（`data-field=` 0件） |
| イベント結線 | `addEventListener` | インライン `onclick="App.…"` が 64箇所 |

つまりこのモックは、**開いても保存できないし、犬体図に描くこともできません。**
見た目だけが確定していて、中身が入っていない状態です。

## import 禁止（LEVEL D-1）

`src/` `worker/` `scripts/` のどこからも `design/` を参照してはいけません。
`npm run check` に組み込まれた `scripts/design-isolation-guard.mjs` が機械的に検出し、
参照が1件でもあれば EXIT 1 で落とします。

この規則には由来があります。過去に**動いていた V1 を参照専用に凍結し、
動かない静的モックを `src/` の正本に据える**という取り違えが起きました
（移設 plan「前版の誤り」）。納品物が動かなくなる事故なので、二度と起こさないよう
規則ではなくスクリプトで止めています。

`design/` を `src/` の配下に移動することも禁止です。`scripts/build-dist.mjs` の
completeness guard が `src/` 配下の HTML を全列挙して未処理があれば EXIT 1 するため、
外に置いている限り自動的にビルドから隔離されます。ガードはこの位置関係も検査します。

## 貼り替えの方向

統合は「モックか V1 かを選ぶ」作業ではなく、**V1 の JS エンジン（約3,063行）を残したまま
HTML/CSS だけをこの意匠に差し替え、V1 のデータ契約属性（`data-field` 等）を後付けする**
再スキンです。書き直しではありません。

画面の対応関係、`onclick` の撤去方針、歯の値域（V1 3段階 / モック 6段階）の扱いは
`docs/ops/plans/2026-08-21-integration.md` にあります。

なお、このモックにも `images.unsplash.com` と Google Fonts への外部参照が残っています
（`F-20260821-07`）。貼り替えの際にそのまま `src/` へ持ち込まないこと。
