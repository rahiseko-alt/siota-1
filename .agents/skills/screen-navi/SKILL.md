# 画面ナビ (screen-navi)

**このスキルの目的は「一緒に探すこと」ではない。**
先に正解を確定させ、ユーザーには1歩ずつ渡す。

## 発火

### 提案するとき

ユーザーの発言が次のいずれかに当たったら、**提案する**（勝手に始めない）:

- 「どこを押せばいい？」「分からない」「この画面で止まった」
- 画面の文字をそのまま貼ってきた（＝迷っている合図）
- こちらが「マスターの作業です」と渡した手順が、2往復以上進んでいない

**提案の文は1行**: 「画面ナビに切り替えますか？（1画面につき1つだけ指示します）」

### 始めるとき

**受諾されてから**開始する。「はい」「やって」「頼む」で十分。

## 手順

### 0. 先に正解を確定させる（**ここを飛ばしたら、このスキルは失敗している**）

ユーザーに何かを押させる**前に**、最後までの手順を自分の中で完成させる。

- 提供元の**公式ドキュメントを取得**して組み立てる（`WebFetch` / `WebSearch`）。
  記憶にあるメニュー名で書かない。UI は変わる
- そこで**用語の意味も確定させる**（例: Cloudflare の Roll と Delete の違い）。
  「押すとどうなるか」を答えられない操作を、指示に含めない
- 公式の記述が見つからない・古い可能性があるときは、**ユーザーに現在の画面を見せてもらってから**組み立てる。
  「たぶんこの辺」で出さない

**確定できなかったら、確定できないと言う。** それはこのスキルでは失敗ではない。
失敗は、確定していないものを確定したように出すこと。

### 1. 全体像を1回だけ出す

- 何歩で終わるか
- 途中で**戻せなくなる歩**がどれか
- 終わったとき何が変わっているか

3行以内。ここで長く説明しない。

### 2. 1メッセージ＝1歩

各歩に必ず入れるもの:

| | 中身 |
|---|---|
| **場所** | どの画面・どの区画にいるか。**動作より先に言う**（「〇〇の画面で、△△を押す」） |
| **動作** | 押す/入力する対象を、**画面に出ている文字そのまま**で名指しする |
| **結果** | 押したら**何が出るか**。ユーザーはこれと見比べて答える |

禁止:

- **方向だけで指さない**（「右上の」「下のほう」）。文字で指す。位置は補助にとどめる
- 専門語を出さない。英語ラベルはそのまま引用し、意味を1語添える
- 1歩に2つ以上の操作を混ぜない（同じ画面の連続クリックだけは `A > B` にまとめてよい）
- 全部で12歩を超えるなら、区切って章立てにする

### 3. 証拠で着地を確かめる（**毎歩ではない**）

**証拠を求める4つの場面だけ**、次の歩を出す前に確認する:

1. 最初に目的の画面へ着いたとき（起点の確定）
2. 画面の内容によって次の歩が変わるとき（分岐）
3. **取り返しのつかない操作の直前**
4. 返ってきた反応が、こちらの書いた「結果」と違うとき

それ以外の歩は、**自己申告で進んでよい**。毎回スクショを求めると誰も進めなくなる。

**受け入れる証拠**（どれか1つで十分）:

- スクリーンショット
- 画面の文字のコピペ
- URL
- **こちらが書いた「結果」の文言を名指しした返答**（「〇〇と出た」）

**受け入れない返答**:

- 「たぶん」「〜だと思う」「似たようなのが出た」
- 期待した文言に**一切触れていない**肯定（「はい」「OK」だけ）

受け入れないときの返し方は**1行**: 「いま画面に出ている文字を、そのまま貼ってください」。
責めない。言い直させるだけ。

### 4. 取り返しのつかない歩の直前

その歩だけ、**何が消えるかを名指しで**書く（「〇〇という名前のものが消えます」）。
「よろしいですか」だけの確認はしない——毎回やると読まれなくなる。

- **戻せるか**を1行
- 戻せないなら、**先に控えを取る指示**を1歩として立てる

### 5. 終わり

- **何が変わったか**を1行で確認する
- 記録が要るものは、この後で `docs/decisions.md` などに残す（ユーザーには見せなくてよい）

## やってはいけないこと（このスキルの失敗そのもの）

1. **反応を見てから次を考える。** 探索を人にやらせるのはナビゲートではない
2. **記憶でメニュー名を書く。** 画面は変わる。取得してから書く
3. 曖昧なまま先へ進む。分からないと言うほうが速い
4. 1メッセージに複数歩・長い説明を詰める

## 役割の分離

**手順の確定**（調べる・組み立てる）と**進行**（1歩ずつ渡す）は別の仕事である。
サブエージェントを起こせる AI は、確定を [`NAVIGATOR.md`](./NAVIGATOR.md) の役割に投げてよい。
起こせない AI は、自分で同じ順にやる。成果物は同じ。
