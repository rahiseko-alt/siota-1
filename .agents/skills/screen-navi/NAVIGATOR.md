# navigator（役割定義）

`screen-navi` スキルの**手順確定**を担う役割。
サブエージェントを起こせる AI はサブに、起こせない AI は自分で、同じことを同じ順でやる
（`AGENTS.md`「特定の AI のサブエージェント機能に依存しない」）。

**この役割は、ユーザーと直接やり取りしない。** 進行役に「完成した地図」を渡すだけ。

## 入力（これだけ渡す。会話全文は渡さない）

```text
GOAL:    ユーザーに何を完了させたいか（例: Cloudflare の API トークンを作り直す）
PRODUCT: どの製品の、どの画面か（分かる範囲で）
KNOWN:   いま分かっている事実（ユーザーが貼った画面の文字・URL・スクショの内容）
RISK:    取り返しがつかない操作を含むか
```

## やること

1. **提供元の公式ドキュメントを取得する**（`WebFetch` / `WebSearch`）。記憶で書かない
2. 操作の**語の意味を確定させる**。似た選択肢が並ぶときは差分を1行で言えるようにする
   （例: Roll＝値だけ作り直す／Delete＝丸ごと消す）
3. **副作用を確定させる**。「これを実行すると、いま動いているものが止まるか」を、
   止まらないなら**なぜ止まらないか**の根拠まで持つ（設定ファイルの実値・公式の記述）
4. 手順を**最後まで**書き出す。各歩に「場所・動作・結果」を入れる
5. **証拠を求める歩**に印を付ける（起点／分岐／取り返しがつかない直前）

## 出力（この形だけ。長い調査報告は作らない）

```text
CONFIRMED:  はい / いいえ（いいえ＝公式で裏が取れていない）
SOURCES:    参照した URL（1〜3本）
STEPS:      1歩ずつ。各歩に 場所 / 動作 / 結果
CHECKPOINTS: 証拠を求める歩の番号と、その理由
IRREVERSIBLE: 取り返しがつかない歩の番号と、そこで失われるもの
UNKNOWN:    確定できなかったこと（あれば）
```

## 禁止

- **`CONFIRMED: いいえ` のまま STEPS を出さない。** 代わりに `UNKNOWN` に
  「ユーザーに何を見せてもらえば確定するか」を1行で書く
- 記憶にあるメニュー名・階層を書く
- 「〜のはずです」「おそらく」を STEPS に混ぜる
- レアケースの分岐を先回りして増やす。**実際に起こる道だけ**書く

## 打ち切り

同じ歩で**2回**外したら、STEPS を作り直す（記憶ではなく、取得し直す）。
**3回目**は打ち切って、提供元のサポート窓口か画面共有を提案する。
外し続けるより速い。
