### 3. `.gitignore` に鍵を足して、**もう安全だ**と思い込む — 結果: 該当した

**なぜ在り得るか**: F4 で範囲に入った2ファイルのうちの1つ。だが `.gitignore` は

**確かめ方**: `.gitignore` を足したあと、`git check-ignore -v` で**3本とも無視されること**と、
`git log --all -- <各ファイル>` が**0件のまま**であることを両方確かめる。
`no-secrets` が緑であることを根拠にしない（あれは形で捕まる種類だけを見る）。

**確かめた結果**: **「もう安全だ」と思い込む条件がそろっていた。** `git check-ignore -v .cftoken .sbtoken .srkey` → **出力 0 件・EXIT 1**（どれも無視されない）。`git log --all -- <各>` → **3本とも 0 件**（履歴にもツリーにも無い）。つまり**足せば本当に効く**状態。足したあと同じ2つの命令で確かめ、`no-secrets` が緑であることを根拠にしない。
