# カルテを消すボタンを、どこに置きますか（マスターに決めてほしいこと）

2026-08-26。前に書いた版は専門用語だらけで読めないものでした。書き直します。

---

## いまの状態

**消す仕組みはもう出来ています。押すボタンだけが、どの画面にもありません。**

だから今は「消せない」だけで、お客さんに迷惑がかかっている状態ではありません。
決めていただきたいのは **ボタンをどこに置くか** の1点だけです。

---

## 大事な前提：消したら戻せません

**ゴミ箱はありません。** 押した瞬間に、写真も文章も無くなります。

「誰が・いつ・どのカルテを消したか」の記録だけは残りますが、**中身は戻りません。**
お客さんに「間違えて消しました、もう一度送ります」はできません。

---

## 消し方の大きさは3つあります

| | 押すと消えるもの | 残るもの |
|---|---|---|
| **① 1枚だけ消す** | X くんの「**8月15日の1回分**」。書いた文章も、その日の写真も。**飼い主さんのスマホからも、その1枚が消えます** | X くんの他の日の記録。飼い主さん |
| **② その子ごと消す** | **X くん本人**と、**今までの記録が全部**。写真も全部 | 飼い主さん。同じ人が飼っている**他の子** |
| **③ お客さんごと消す** | その人が飼っている**子が全員**。その子たちの**記録と写真が全部**。**その人はログインしても何も見えなくなります**（お渡しした招待リンクも効かなくなります） | 他のお客さんだけ |

---

## ボタンを置ける場所は3つ。**押し間違えたときの被害が違います**

| 置く場所 | 押し間違えると… | ひとこと |
|---|---|---|
| **飼い主さんに届いたカルテを開いた画面** | **1枚だけ**消える | **いちばん被害が小さい。** 届いたものを目で見ながら消せる |
| **犬の名前が並んだ一覧の画面** | **隣の子を押すと、その子の記録が全部**消える | まとめて片づけやすいが、**いちばん危ない** |
| **カルテを書いている途中の画面** | 書いている途中のものが消える | 「下書きをやめる」ボタンと**見分けがつきにくい** |

---

## 私のおすすめ

**「① 1枚だけ消す」を、飼い主さんに届いたカルテの画面に置く。**

理由は3つです。

1. 押し間違えても**1枚で済む**
2. 消す前に**中身を目で見られる**（「これは消していいやつだ」と確かめられる）
3. **いま実際に困るのはこれ**。間違えて送ったカルテを引っ込めたい、という場面

「② 子ごと」「③ お客さんごと」は、**必要になってからで間に合います。**
とくに③は影響が段違いなので、押せる場所を作ること自体を、そのとき改めて決めてください。

---

## 決めていただきたいこと

**「どこに置くか」だけ**です。次のどれかを言っていただければ、そのとおりに作ります。

- 「届いたカルテの画面に、1枚だけ消すボタン」（私のおすすめ）
- 「一覧の画面に、子ごと消すボタンも」
- 「いまは置かなくていい」

---

## 参考：安全のために既にやってあること

- **写真を先に片づけてから記録を消します。** 逆にすると、写真だけが誰にも触れない場所に
  取り残されます。順番を間違えたら、命令（`npm run check`）が自動で止めます
- **毎回検査しています。** 「消したら写真が本当に消えているか」を、
  CI（自動の見張り）が毎回数えて確かめています（`npm run verify:delete`・6/6）
