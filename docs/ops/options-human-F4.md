## 1. どうやって確かめたか

`node scripts/verify-options-human.mjs`

本番の `/edit` は Worker が `dist/index.html` に script を3本注入して配っている。
この検査も**同じ3本を同じ順で注入**し、**実物の `ui.js` / `supabase-staff.js`** を載せる。
差し替えるのは外の世界の2つだけ——ログイン（済みの体にする）と `/api/*` の応答。
そのうえで iPhone の画面サイズで、**人がやるのと同じ操作**（開く → 押す → 指で送る）をなぞり、
1パターンにつき写真を撮る。

**この検査は合否を出さない。出すのは写真だけ。** 合否は人が写真を見て決める（`D-14` と同じ）。
写真は `.human/options/`（`npm run walk` と同じく追跡外）。

実データでの裏づけは別口で取った——`npm run walk`（EXIT 0）と
`npm run verify:roundtrip`（34/34 PASS・`16b. 飼い主: 使用オプション "アメージング"` を含む）。
本番の既定9件（アメージング／シセルリノ／ジュエルT／ジュエルM／NAMAKERA／キラトリ／
グロスチャー／皮膚spa／被毛spa）が④に並ぶことを写真で確認した。

## 3. なぜそうなっていたか（原因）

### 原因1 — ④への入口が2つあり、1つしか塞いでいなかった

⑦の帯は最初から隠してあり（`sec-options` の `hidden`）、これを外すのは
**「犬を選んで④に入る」道を通ったときだけ**。
ところが画面のいちばん上の帯にある「03 カルテ作成」は、いつでも押せて、
**その道を通らずに④を開いてしまう**。

前回（PR #58）塞いだ「＋新規カルテを作成する」と**まったく同じ穴**が、
段のタブにも空いていた。前回は入口を1つしか見ていなかった。

### 原因2 — 読み込みに失敗しても、黙って「オプションが無い店」のふりをしていた

店舗のオプションを取りに行く口が失敗したとき、失敗を丸ごと握り潰していた。
その結果、**認証切れ（401）でも、2店舗所属（409）でも、サーバの故障（502）でも、
画面はどれも同じ「帯が消えた④」**になっていた。
どこを直せばよいか、画面を見ても分からない状態だった。

### 原因3 — 起動に失敗したときのお知らせが、存在しない場所に書かれていた

失敗したら画面に出す、という処理は書いてあったが、
書き込む先の名前（`.owner-list`）が**この画面に1つも存在しない**。
つまり何が起きても、マスターの画面には**何も出なかった**。

## 5. まだ残っているもの（マスターの判断が要る）

### ④ ホーム画面のアイコンから開くと、いまも出ない

**何が起きるか**: ホーム画面に追加したアイコンから開くと、`/` という別の入口が開く。
そこは**練習用の画面**で、出てくる犬は実在しない4頭（ポンチ・レオ・モカ・モモ）。
「Google でログイン」を押してもログインせず、そのまま練習用の一覧に進む。
当然オプションも出ない。

**すぐできる見分け方**: ②の一覧に**ポンチ・レオ・モカ・モモ**が出ていたら、これ。

**戻せるか**: 戻せる。`/` を開いたら `/edit` へ送る、という1行の変更で済む。

**間違えたとき何が失われるか**: `/` は `npm run walk`（人が使えるかを絵で見る検査）が
使っている入口でもある。ここを変えると、その検査の前提が変わる。

**おすすめ**: **変える**。お客さんの店で使う入口が練習用の画面につながっているのは、
今回の症状そのものを生む。ただし `npm run walk` の入口を先に付け替える必要があるので、
**マスターの「やってよい」を待つ**。

### ⑨ 本番の店舗のオプションが、本当に空になっている可能性

これだけは、こちらからは確かめられない（本番は認証が要り、鍵は受け取らない）。
過去に「読み込む前に保存ボタンを押すと、一覧を空で上書きしてしまう」不具合が実在した。

## 6. マスターにお願いしたいこと（1つだけ）

**④カルテ作成の画面を、上から下まで指で送りながら、1画面ずつスクショを撮ってください（6〜7枚）。**

理由: ⑦の帯は④の**下から2番目**にあり、iPhone では**指で約6回**送らないと出てきません
（画面の高さ664px に対して、帯は上から3254px の位置）。
1枚だけだと、どの原因かが永久に決まりません。

そのとき、次の3つのどれに当てはまるかで**原因が1つに決まります**:

| 写真に写っているもの | 原因 |
|---|---|
| ②の一覧が**ポンチ・レオ・モカ・モモ** | 上の④（ホーム画面のアイコン） |
| ④の見出しに**犬の名前が無い** | 原因1（今回直した・「03 カルテ作成」から入っている） |
| 犬の名前は在るのに帯だけ無い | 原因2 か ⑨（今回から**理由が画面に出る**ので、その文言を撮ってください） |
